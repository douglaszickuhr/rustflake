# Vários idiomas (pt / en / es) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Interface e mensagens do app em pt/en/es, padrão pelo idioma do macOS, seletor 🌐 na barra lateral que troca na hora e fica salvo.

**Architecture:** `rust-i18n` (global de processo, o mesmo do `gpui-component`) com um `locales/app.toml` (formato v2: cada chave com `en`/`pt`/`es`) em cada crate. `rb-core::config` guarda `Settings { language }` em `settings.toml`; `rb-app/src/lang.rs` resolve o idioma, aplica e avisa a UI por um `Global`. Dois testes por crate garantem que toda chave usada existe e tem os três idiomas.

**Tech Stack:** Rust 2024, rust-i18n 4.2.4, sys-locale 0.3.2 (ambos já no `Cargo.lock`), gpui-kit 0.7.3.

**Spec:** `docs/superpowers/specs/2026-10-15-i18n-design.md`

## Global Constraints

- Nenhum crate novo no `Cargo.lock`: `rust-i18n = "4.2"`, `sys-locale = "0.3"` (versões já resolvidas).
- O português atual vira o texto `pt` sem mudança; `en` e `es` são traduções novas, naturais (não literais).
- Fora: mensagens do servidor (Postgres/Snowflake), logs `tracing`, comentários, nomes de idioma no seletor.
- Fallback `en` (`i18n!("locales", fallback = "en")`).
- Testes nunca chamam `rust_i18n::set_locale` (global, testes rodam em paralelo); para conferir um idioma, `t!("chave", locale = "pt")`.
- Chaves por área: `conn.*`, `sidebar.*`, `tree.*`, `sql.*`, `table.*`, `grid.*`, `filter.*`, `quick.*`, `lang.*`, `app.*`, e no core `err.*`.

## Review Focus

1. Chave usada no código sem entrada no TOML: o `rust-i18n` mostraria a chave crua na tela — o teste de varredura (Task 1) pega.
2. Troca de idioma com a árvore expandida: rótulos "carregando…", "Tabelas (n)" mudam na hora (Task 4: `SchemaTree` observa `Lang`).
3. `settings.toml` inválido ou com idioma desconhecido: abre em `auto`, sem erro na tela (Task 1).
4. macOS em `pt-PT`, `es-419`, `zh-Hans`: pt, es, en (Task 1, `resolve`).
5. Interpolação: `%{n}` presente nos três idiomas de cada chave que o usa — teste de completude confere as variáveis (Task 1).

`i18n_check.rs` (core; o mesmo teste no core chama `check` com os caminhos do core):

```rust
//! Guardas da tradução: chave usada sem entrada, idioma faltando, variável diferente entre idiomas.

use std::collections::BTreeSet;
use std::path::Path;

const LANGS: [&str; 3] = ["en", "pt", "es"];

/// Chaves de `t!("…"` em todos os `.rs` de `dir`.
fn used_keys(dir: &Path, out: &mut BTreeSet<String>) {
    for e in std::fs::read_dir(dir).unwrap().flatten() {
        let p = e.path();
        if p.is_dir() {
            used_keys(&p, out);
        } else if p.extension().is_some_and(|x| x == "rs") {
            let src = std::fs::read_to_string(&p).unwrap();
            for part in src.split("t!(\"").skip(1) {
                out.insert(part.split('"').next().unwrap().to_string());
            }
        }
    }
}

fn vars(s: &str) -> BTreeSet<&str> {
    s.split("%{").skip(1).filter_map(|p| p.split('}').next()).collect()
}

/// Folhas `chave.pontuada -> {en, pt, es}` do TOML v2.
fn entries(v: &toml::Table, prefix: &str, out: &mut Vec<(String, toml::Table)>) {
    for (k, v) in v {
        let Some(t) = v.as_table() else { continue };
        let key = if prefix.is_empty() { k.clone() } else { format!("{prefix}.{k}") };
        if t.contains_key("en") {
            out.push((key, t.clone()));
        } else {
            entries(t, &key, out);
        }
    }
}

pub fn check(src: &Path, toml_path: &Path) {
    let file: toml::Table = std::fs::read_to_string(toml_path).unwrap().parse().unwrap();
    let mut all = Vec::new();
    entries(&file, "", &mut all);
    let mut problems = Vec::new();
    for (key, t) in &all {
        let en = t.get("en").and_then(|v| v.as_str()).unwrap_or("");
        for l in LANGS {
            match t.get(l).and_then(|v| v.as_str()) {
                Some(s) if !s.is_empty() && vars(s) == vars(en) => {}
                _ => problems.push(format!("{key}: `{l}` ausente, vazio ou com variáveis diferentes do `en`")),
            }
        }
    }
    let defined: BTreeSet<&str> = all.iter().map(|(k, _)| k.as_str()).collect();
    let mut used = BTreeSet::new();
    used_keys(src, &mut used);
    problems.extend(used.iter().filter(|k| !defined.contains(k.as_str())).map(|k| format!("{k}: usada no código, ausente no TOML")));
    assert!(problems.is_empty(), "{}:\n{}", toml_path.display(), problems.join("\n"));
}
```

```rust
/// Idioma da interface; `Auto` segue o macOS.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Language {
    #[default]
    Auto,
    Pt,
    En,
    Es,
}

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Settings {
    #[serde(default)]
    pub language: Language,
}

pub fn settings_path() -> PathBuf {
    app_dir().join("settings.toml")
}

/// Ausente ou inválido = padrão (com aviso no log): preferência não vale uma tela de erro.
pub fn load_settings(path: &Path) -> Settings {
    match std::fs::read_to_string(path) {
        Ok(s) => toml::from_str(&s).unwrap_or_else(|e| {
            tracing::warn!("{}: {e}", path.display());
            Settings::default()
        }),
        Err(_) => Settings::default(),
    }
}

pub fn save_settings(path: &Path, s: &Settings) -> Result<(), DbError> {
    write_atomic(path, &toml::to_string_pretty(s).map_err(|e| DbError::Config(e.to_string()))?)
}
```

`lang.rs`:

```rust
//! Idioma da interface: resolve a escolha (ou o do macOS), aplica no `rust-i18n` e avisa a UI.

use gpui_kit::*;
use rb_core::config::{self, Language, Settings};

/// Idioma escolhido; trocar o global avisa quem observa (`cx.observe_global::<Lang>`).
pub struct Lang(pub Language);

impl Global for Lang {}

pub fn resolve(choice: Language, os: Option<&str>) -> &'static str {
    match choice {
        Language::Pt => "pt",
        Language::En => "en",
        Language::Es => "es",
        Language::Auto => match os.map(|l| l.split(['-', '_']).next().unwrap_or("").to_ascii_lowercase()).as_deref() {
            Some("pt") => "pt",
            Some("es") => "es",
            _ => "en",
        },
    }
}

fn apply(choice: Language, cx: &mut App) {
    rust_i18n::set_locale(resolve(choice, sys_locale::get_locale().as_deref()));
    cx.set_global(Lang(choice));
}

/// Na partida, antes de abrir a janela.
pub fn init(cx: &mut App) {
    apply(config::load_settings(&config::settings_path()).language, cx);
}

/// Troca já, salva em segundo plano e redesenha tudo.
pub fn set(choice: Language, cx: &mut App) {
    apply(choice, cx);
    let path = config::settings_path();
    cx.background_spawn(async move {
        if let Err(e) = config::save_settings(&path, &Settings { language: choice }) {
            tracing::warn!("settings.toml: {e}");
        }
    })
    .detach();
    cx.refresh_windows();
}

/// Rótulo do seletor: nome do idioma na própria língua; `Auto` mostra o que resolveu.
pub fn label(choice: Language) -> String {
    let name = |code: &str| match code {
        "pt" => "Português",
        "es" => "Español",
        _ => "English",
    };
    match choice {
        Language::Auto => format!("Auto ({})", name(resolve(Language::Auto, sys_locale::get_locale().as_deref()))),
        other => name(resolve(other, None)).to_string(),
    }
}
```
