# UX A: App Frame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the sidebar with the canvas frame:

- a title row with tabs, the context bar and ⌘K;
- an icon rail and an objects panel;
- a status bar;
- an environment per connection;
- the canvas palette and the Geist font.

**Architecture:**

- `rb-core/config.rs` gets `Environment`.
- `rb-app/appearance.rs` gets a pure `palette(mode)` plus an `apply_palette` that runs after every `Theme::change`.
- A new `rb-app/frame.rs` holds the pure helpers: context-bar text and the environment's label/color.
- `workspace.rs` changes `render`/`render_sidebar` into title row + rail + panel + main + status bar. The current actions are reused: `connect`, `pick_context`, `open_admin`, `show_history`, `quick_open`, `pick_language`, `pick_theme`, `edit_db_filter`.

**Tech Stack:** Rust 2024, gpui-kit 0.7.3 (`TitleBar::window_options`, `Popover`, `Theme`), rust-i18n.

**Spec:** `docs/superpowers/specs/2026-10-16-ux-frame-design.md`

## Global Constraints

- **Do not commit.** The user commits.
- Code comments are in Portuguese, short, and say why.
- rb-app tests use `#[::core::prelude::v1::test]`.
- All UI text goes in `crates/rb-app/locales/app.toml`, in en/pt/es.
- Colors (dark):
  - background `#0B0B0C`, surface `#111113`, secondary `#17171A`;
  - border `#1D1D21`, strong border `#26262B`;
  - fg `#E8E8EC`, muted `#9A9AA3`, tertiary `#7C7C85`;
  - accent `#6CC4F0`, prod `#F0A35E`.
- Colors (light):
  - background `#FAFAFA`, surface `#FFFFFF`, secondary `#F0F0F2`;
  - border `#E4E4E8`, strong border `#D4D4DA`;
  - fg `#141416`, muted `#5E5E66`;
  - accent `#1F7FB0`, prod `#C46A1E`.
- Text/background pairs need contrast ≥ 4.5:1.
- The title row is 44px with content starting 84px from the left. The rail is 52px. The panel is 180–640px, default 260. The status bar is 28px.
- Geist and Geist Mono (OFL) are embedded in the binary.
- No new crates.

## Review Focus

1. A `connections.toml` written before this change (no `environment`) loads with `None` and saves without the key.
2. No connection open: the context bar says "Connect…" and the main area lists the connections. The rail never panics without a connection (Access hidden, Objects shows a hint).
3. The active tab belongs to connection X while the "current" connection is Y. The context bar and the PROD border follow the **active tab**, so writing to PROD is never mislabeled.
4. Switching light/dark or auto (macOS) keeps the palette. The override is reapplied after every `Theme::change`.
5. A long role/warehouse/db name in the context bar truncates with "…" and doesn't push the tabs or the ⌘K button off the row.

use gpui_kit::{Hsla, Rgba, rgb};

/// Cores do canvas "Rustflake UX Concepts"; o claro é derivado do escuro.
#[derive(Clone, Copy)]
pub struct Palette {
    pub background: Hsla,
    pub surface: Hsla,
    pub secondary: Hsla,
    pub border: Hsla,
    pub border_strong: Hsla,
    pub foreground: Hsla,
    pub muted: Hsla,
    pub tertiary: Hsla,
    pub accent: Hsla,
    pub accent_foreground: Hsla,
    pub prod: Hsla,
}

pub fn palette(dark: bool) -> Palette {
    let c = |hex: u32| -> Hsla { rgb(hex).into() };
    if dark {
        Palette {
            background: c(0x0B0B0C),
            surface: c(0x111113),
            secondary: c(0x17171A),
            border: c(0x1D1D21),
            border_strong: c(0x26262B),
            foreground: c(0xE8E8EC),
            muted: c(0x9A9AA3),
            tertiary: c(0x7C7C85),
            accent: c(0x6CC4F0),
            accent_foreground: c(0x0B0B0C),
            prod: c(0xF0A35E),
        }
    } else {
        Palette {
            background: c(0xFAFAFA),
            surface: c(0xFFFFFF),
            secondary: c(0xF0F0F2),
            border: c(0xE4E4E8),
            border_strong: c(0xD4D4DA),
            foreground: c(0x141416),
            muted: c(0x5E5E66),
            tertiary: c(0x6E6E76),
            accent: c(0x1F7FB0),
            accent_foreground: c(0xFFFFFF),
            prod: c(0xB0601A),
        }
    }
}

/// Razão de contraste WCAG.
fn contrast(a: Hsla, b: Hsla) -> f32 {
    let lum = |h: Hsla| {
        let c: Rgba = h.into();
        let ch = |v: f32| if v <= 0.03928 { v / 12.92 } else { ((v + 0.055) / 1.055).powf(2.4) };
        0.2126 * ch(c.r) + 0.7152 * ch(c.g) + 0.0722 * ch(c.b)
    };
    let (x, y) = (lum(a), lum(b));
    (x.max(y) + 0.05) / (x.min(y) + 0.05)
}

/// O `Theme::change` recarrega o tema registrado; reaplicar depois de cada troca.
fn apply_palette(theme: &mut Theme) {
    let p = palette(theme.mode.is_dark());
    let t = &mut theme.colors;
    t.background = p.background;
    t.foreground = p.foreground;
    t.border = p.border;
    t.input = p.border_strong;
    t.ring = p.accent;
    t.caret = p.accent;
    t.popover = p.surface;
    t.popover_foreground = p.foreground;
    t.muted = p.secondary;
    t.muted_foreground = p.muted;
    t.secondary = p.secondary;
    t.secondary_hover = p.border_strong;
    t.secondary_active = p.border_strong;
    t.secondary_foreground = p.foreground;
    t.accent = p.secondary;
    t.accent_foreground = p.foreground;
    t.primary = p.accent;
    t.primary_hover = p.accent.opacity(0.9);
    t.primary_active = p.accent.opacity(0.8);
    t.primary_foreground = p.accent_foreground;
    t.link = p.accent;
    t.title_bar = p.background;
    t.title_bar_border = p.border;
    t.status_bar = p.background;
    t.status_bar_border = p.border;
    t.sidebar = p.background;
    t.sidebar_border = p.border;
    t.sidebar_foreground = p.foreground;
    t.tab_bar = p.background;
    t.tab = p.background;
    t.tab_active = p.secondary;
    t.tab_foreground = p.muted;
    t.tab_active_foreground = p.foreground;
    t.list = p.background;
    t.list_hover = p.secondary;
    t.list_active = p.secondary;
    t.list_even = p.background;
    t.list_head = p.background;
    t.table = p.background;
    t.table_head = p.background;
    t.table_head_foreground = p.muted;
    t.table_hover = p.secondary;
    t.table_even = p.background;
    t.table_row_border = p.border;
    t.window_border = p.border;
    t.selection = p.accent.opacity(0.3);
}
```

//! Peças puras da moldura: texto da barra de contexto e cor do ambiente.

use gpui_kit::Hsla;
use rb_core::config::Environment;
use rb_core::dialect::Dialect;

use crate::appearance::palette;

/// Partes da barra de contexto; o que falta vira "—".
pub fn context_parts(env: Option<Environment>, dialect: Dialect, user: &str, role: Option<&str>, warehouse: Option<&str>, search_path: &[String]) -> Vec<String> {
    let dash = |v: Option<&str>| v.filter(|s| !s.is_empty()).unwrap_or("—").to_string();
    let mut out: Vec<String> = env.map(|e| e.label().to_string()).into_iter().collect();
    let first = search_path.first().map(String::as_str);
    match dialect {
        Dialect::Snowflake => out.extend([dash(role), dash(warehouse), dash(first)]),
        Dialect::Postgres => out.extend([dash(Some(user)), dash(first)]),
    }
    out
}

/// Só produção ganha cor (borda da janela e rótulo).
pub fn env_color(env: Option<Environment>, dark: bool) -> Option<Hsla> {
    (env == Some(Environment::Production)).then(|| palette(dark).prod)
}
```

> If `Dialect` has more variants, the `match` must cover them (the compiler will say so). Use `_ => out.extend([dash(Some(user)), dash(first)])`.
